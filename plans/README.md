# Previously Plans

This folder holds active plans, exploratory thinking and archived planning
material. Accepted project knowledge lives in [`docs/`](../docs/README.md).

- `active/` holds current implementation plans.
- `exploration/` holds product, content and technical exploration that is not
  yet a plan.
- `archive/` holds finished or abandoned plans, kept for context.

Number plans in order (`0001-short-name.md`) and use
[`PLAN_TEMPLATE.md`](PLAN_TEMPLATE.md) for new active plans. Every substantial
plan starts with a **Review Attention** summary so its major decisions and
surprises are visible without reading every section.

When a plan becomes accepted direction, record the durable decision as an ADR
in `docs/decisions/` and update `docs/architecture/` so it describes the
system as it now is. Do not edit finished plans to track later renames.

Plans live in this public repository. Never put show content or spoilers in a
plan; refer to the content repository instead (see
[docs/architecture/README.md](../docs/architecture/README.md)).
